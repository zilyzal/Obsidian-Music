## Obsidian Music 1.2

Fixes and polish on top of the 1.1 redesign.

**Changed**
- Shuffle at the top is now a round icon-only button, as in the mockup.
- The view pill (Latest, Favorites, ...) is smaller, with smaller text.
- The mini player now has a previous-song button next to play and next.
- Background glows and glass shards carry a little more colour, and cover-derived accent colours are slightly richer.

**Faster**
- Play/pause and song changes no longer redraw every row of a long list; only the playing row updates.
- Rows scrolled back into view skip artwork loading when the cover is already in memory.

**Install note**
Builds are signed with a debug key that is not guaranteed to match earlier versions, so Android may refuse to install this over 1.1.0 or 1.0.0. If that happens, uninstall the old one first (your starred songs will reset).

Download: `ObsidianMusic.apk` below.
